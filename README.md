🍦 Ice Cream Sales Prediction Using Polynomial Regression
📌 Overview

This project focuses on predicting ice cream sales based on temperature using Polynomial Regression, a machine learning technique that can model non-linear relationships between variables.

The project explores how changes in temperature can affect ice cream sales and uses historical data to build a predictive model.

🎯 Objective

The main objective of this project is to:

Understand the relationship between temperature and ice cream sales.

Build a Polynomial Regression model for prediction.

Visualize the relationship between temperature and sales.

Predict expected ice cream sales for different temperatures.

Understand the practical application of regression in machine learning.

📊 Dataset

The dataset contains information about temperature and corresponding ice cream sales.

Features

Temperature – The temperature recorded for a particular day.

Sales – The amount of ice cream sold at that temperature.

Temperature is used as the input feature, while ice cream sales are the target variable.

🧠 Machine Learning Algorithm
Polynomial Regression

Polynomial Regression is a type of regression analysis used when the relationship between the independent and dependent variables is not completely linear.

In this project, Polynomial Regression is used to capture the non-linear relationship between temperature and ice cream sales.

The model learns patterns from the existing data and uses them to estimate sales for new temperature values.

🔄 Project Workflow

Import and explore the dataset.

Analyze the relationship between temperature and sales.

Visualize the dataset.

Prepare the data for machine learning.

Apply Polynomial Regression.

Train the model using the available data.

Generate predictions.

Visualize the predicted regression curve.

Evaluate the model's performance.

📈 Results

The Polynomial Regression model is able to capture the relationship between temperature and ice cream sales.

The visualization of the regression curve helps demonstrate how predicted ice cream sales change as temperature increases or decreases.
